## Checked and found sound
- Headline and provider links go through `safeUrl` and open with `rel="noopener noreferrer"`. No `innerHTML` in `site/app.js`; the DOM is built with `h()`.
- `learning.walk_forward` trains only on outcomes already known at the split (no look-ahead at the split).
- Serialised publishing: `concurrency: group: pages, cancel-in-progress: false`; the Pages deploy is atomic at artifact level. No `pull_request` trigger, so no secrets reach untrusted code.
- Telegram secrets are read from the environment only; none is written to `data.json`/`state.json` (not re-grepped across all logs this round).

## Architectural risks (not fixed)
- Third-party actions are pinned by tag (`checkout@v4`, `setup-python@v5`, Pages actions), not by commit SHA.
- Ledger has unique ids but no hash chain; the id is a truncated SHA-1 (12 hex) of symbol, horizon, date and side. Tampering on the `data` branch by someone with write access is now ignored on read for repeated ids, but not detected for edited or deleted lines.
- `update.yml` gives the whole job `contents: write`, including the test step. The ledger push happens in the build step before the deploy job, so a failed deploy can leave new ledger lines without a published site.
- `catalog.pick` orders by never-analysed first then stalest, but there is no stated maximum-age guarantee or test for it.
- Fundamentals are Yahoo-only for India; no corporate-action-aware price comparison was audited.
- The walk-forward test has one split and a date-cluster bootstrap. Overlapping horizons (5, 20, 60 days) make dates dependent, so the interval is probably too narrow (a block bootstrap is not implemented). No final untouched holdout; no multiple-testing correction across horizons and factors. The "no edge" result is therefore the conservative reading, but the intervals themselves are unreliable.
- Survivorship bias is disclosed but not removed (current listings only).
- News: name matching is heuristic; ISIN-based attribution is not implemented. Sentiment word list and weights are unvalidated; no labelled test set, precision or recall exists. Price reaction is shown as "confirms", which is not causal evidence.
- AI: the 50/50 blend is unjustified without labelled data. Done: shadow mode (see finding 9). A labelled sample is still needed before any weight above zero.
